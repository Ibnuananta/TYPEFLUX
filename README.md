# TypeFlux

A minimal typing test website inspired by Monkeytype, built with plain HTML, CSS, and JavaScript.

## Features

- 15s, 30s, 60s, and 120s test modes
- Live WPM calculation
- Live accuracy tracking
- Correct/wrong character highlighting
- Dark/light theme toggle
- Fully static, no backend needed
- Ready for GitHub Pages

## Files

```txt
index.html
style.css
script.js
README.md
```

## Run locally

Open `index.html` in your browser.

## Deploy with GitHub Pages

1. Go to **Settings → Pages**.
2. Source: **Deploy from a branch**.
3. Branch: **main**, folder: **root**.
4. Save.

Your site will be available at:

```txt
https://ibnuananta.github.io/TYPEFLUX/
```

## Ideas for your own style

- Rename `TypeFlux` to your own brand.
- Change the CSS variables in `:root`.
- Add custom word categories.
- Add user profile stats using localStorage.
- Add sound effects and keyboard animations.
