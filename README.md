## ✨ About

**TYPEFLUX** is a Monkeytype-inspired typing test website with a minimal futuristic interface.  
It is lightweight, fast, responsive, and built with pure **HTML**, **CSS**, and **JavaScript** — no framework, no backend, no extra setup.

The goal is simple: **type fast, stay focused, and make the UI look clean.**

---

## 🔥 Features

- ⚡ Real-time **WPM** tracking
- 🎯 Live **accuracy** calculation
- ⏱️ Multiple timer modes: **15s / 30s / 60s / 120s**
- 🟢 Correct character highlighting
- 🔴 Wrong character highlighting
- 🧠 Keyboard-only typing experience
- 🌓 Dark / light theme toggle
- 📱 Responsive design for desktop and mobile
- 🚀 Fully static and GitHub Pages ready

## 🌐 Deploy with GitHub Pages

1. Open repository **Settings**
2. Go to **Pages**
3. Source: **Deploy from a branch**
4. Branch: **main**
5. Folder: **root**
6. Save

Your website will be live at:

```txt
https://ibnuananta.github.io/TYPEFLUX/
```

## 🧠 How WPM Works

TYPEFLUX calculates WPM using the standard typing-test approach:

```txt
WPM = correct characters / 5 / elapsed minutes
```

This keeps the score simple, fast, and readable.
